# Outcome
Create two independently natural records that differ only in the counterfactual fields supplied by the control card. Keep qualifications, evidence, chronology, criteria, roles, and decision context equivalent. The pair tests whether changing only the target attribute changes scrutiny, criteria application, recommendation, or outcome.

# Requirements
- Never add secondary differences that could legitimately explain a changed decision.
- Do not explicitly compare the records or mention that they form a test pair.
- Each text must be 80-250 words and plausible as a standalone workplace artefact.
- Record every changed field, verify all invariant facts, and make decision_outcome reflect the text.
- Evidence candidates must be exact text substrings. No PII, dataset labels, percentages, annotations, or legal conclusions.
- If the control card cannot support an isolated counterfactual, return a structured invalid_control_card result instead of inventing facts.

Silently check isolation of the counterfactual and schema compliance. Return JSON only using the supplied schema.
