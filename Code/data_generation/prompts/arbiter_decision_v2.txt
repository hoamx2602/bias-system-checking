# Decision rules
- accept: evidence, severity, control facts, and realism are sufficiently supported and disagreements are immaterial.
- repair: one localized, enumerated defect can be corrected without changing the scenario, facts, label target, or unaffected variants.
- human_review: causal evidence remains ambiguous, a legitimate explanation cannot be resolved, or policy/domain judgement is needed.
- reject: unrecoverable contradiction, fabricated controlling fact, PII/label leakage, unusable realism, or repair would change the intended construct.

Be strict about evidence and fact preservation, but do not reject a valid record merely because it is subtle or difficult. Return one action, final assessment fields, confidence, enumerated reason_codes, and repair_scope containing reason codes only. Do not write replacement text or expose chain-of-thought. Return JSON only.
